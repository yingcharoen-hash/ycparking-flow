เข้าใจสถานการณ์เลยครับ! เรื่อง "เงินทอน (Float)" เป็นเรื่องจุกจิกที่ทำให้ตัวเลขหน้างานกับตัวเลขในระบบไม่ตรงกันบ่อยมากครับ

คำว่า "หักลบด้วยมือเพื่อคงเหลือเงินทอนไว้" ผมขออนุญาตแยกเป็น 2 กรณี เพื่อความชัวร์ว่าผมเข้าใจตรงกับหน้างานของคุณลูกค้านะครับ:

### **กรณีที่ 1: เงินทอน 200 มีอยู่แล้วตั้งแต่เริ่มกะ (เป็นทุนถาวร)**
*   **เริ่มกะ:** ในลิ้นชักมีเงินทอนนอนอยู่แล้ว 200 บาท
*   **ระหว่างกะ:** รถออกตลอดวัน แอปคำนวณรายได้จากมิเตอร์ได้ **1,000 บาท**
*   **จบกะ:** ในลิ้นชักจะมีเงินปนกันคือ 1,200 บาท (ทุน 200 + รายได้ 1000)
*   **ตอนส่งเงิน:** พนักงานหยิบเงินให้การเงินแค่ **1,000 บาท** (ตามที่แอปบอก) และทิ้ง 200 บาทไว้ในลิ้นชักให้กะต่อไป
*   👉 *ถ้าเป็นกรณีนี้:* แอปในปัจจุบันทำงานได้สมบูรณ์แล้วครับ เพราะแอปสนใจแค่ "รายได้ 1,000" ไม่สนใจเงินทอนที่นอนอยู่ในเก๊ะ พนักงานก็แค่พิมพ์ช่องเงินสด = 1000 ก็จบเลย

### **กรณีที่ 2: ต้องหักเงินทอน "ออกจากรายได้" ของรอบนั้นๆ**
*   **เริ่มกะ:** ในลิ้นชัก **ไม่มีเงินทอนเลย (0 บาท)**
*   **ระหว่างกะ:** แอปคำนวณรายได้จากมิเตอร์ได้ **1,000 บาท**
*   **จบกะ:** ในลิ้นชักมีเงิน 1,000 บาท
*   **ตอนส่งเงิน:** การเงินบอกว่า "เก็บเงินไว้ทอนกะต่อไป 200 นะ ส่งมาให้พี่แค่ **800 บาท** พอ"
*   👉 *ถ้าเป็นกรณีนี้:* แอปปัจจุบันจะแจ้งเตือน Error ทันทีครับ เพราะแอปคำนวณได้ 1,000 แต่พนักงานกรอกส่งเงินแค่ 800 ยอดมันจะไม่ตรงกัน 

**🛠️ วิธีแก้ (ถ้าเป็นแบบกรณีที่ 2):**
ผมจะต้องเพิ่มช่องในแอปชื่อว่า **"หักเงินไว้เป็นเงินทอน"** ให้พนักงานกรอกเลข 200 ลงไป
แอปจะเปลี่ยนสูตรเป็น: `(รายได้จากมิเตอร์ 1,000) - (หักเป็นเงินทอน 200) = ยอดที่ต้องส่งการเงิน (800)`
แบบนี้ตัวเลขในระบบจะเป๊ะ และฝ่ายตรวจสอบก็จะเข้าใจว่าทำไมเงินสดถึงหายไป 200 บาทครับ

หน้างานจริงของคุณลูกค้า ทำงานแบบ **กรณีที่ 1** หรือ **กรณีที่ 2** ครับ?

เหตุการณ์นี้มักจะเกิดจาก 2 สาเหตุหลักครับ:
1. การตั้งค่าการเข้าถึง (Who has access) อาจจะยังไม่ได้เปิดเป็นสาธารณะ
2. บราวเซอร์มือถือบล็อกการดึงข้อมูลข้ามโดเมน (CORS)

เพื่อหาสาเหตุที่แท้จริง ผมเพิ่งอัปเดตโค้ดแอปบนมือถือให้มัน **"ฟ้อง Error แบบละเอียด"** ออกมาที่หน้าจอแล้วครับ

**รบกวนคุณลูกค้าช่วยผมเช็ค 2 อย่างนี้นะครับ:**

### อย่างแรก: เช็ค Error บนมือถือ 📱
1. เปิดแอปบนมือถือ **กดรีเฟรช 1 รอบ**
2. กดปุ่มดึงข้อมูลอีกครั้ง
3. คราวนี้มันจะมีแถบสีแดงขึ้นว่า `⚠️ Error: ...` รบกวนคุณลูกค้าบอกผมหน่อยครับว่าหลังคำว่า Error มันเขียนข้อความภาษาอังกฤษว่าอะไร? (เช่น Failed to fetch, Unexpected token, etc.)

### อย่างที่สอง: เช็คสิทธิ์ใน Google Apps Script 💻
ตอนที่คุณลูกค้ากด Deploy -> New version ตอนแรก รบกวนเช็คให้ผมหน่อยครับว่าช่อง **Who has access (ผู้มีสิทธิ์เข้าถึง)** ถูกตั้งค่าเป็น **Anyone (ทุกคน)** แล้วหรือยัง? (ถ้าเผลอตั้งเป็น Only myself หรือ เฉพาะฉัน ระบบมันจะบล็อกไม่ให้แอปดึงข้อมูลได้ครับ)

ได้ผล Error ว่ายังไง พิมพ์บอกผมได้เลยนะครับ ผมรอแก้ปัญหาให้ทันทีครับ!

แสดงว่าตลอดมาคุณลูกค้านำโค้ดทั้ง 2 ส่วนไปแปะไว้ใน **Google Apps Script** ทั้งหมดเลยใช่ไหมครับ (คือมีไฟล์ `Code.gs` เป็นหลังบ้าน และไฟล์ `Index.html` เป็นหน้าเว็บ)

**ถ้างั้นเรามาอัปเดตโค้ดใน Apps Script ให้ถูกต้องสมบูรณ์กันครับ!**
รอบนี้รบกวนคุณลูกค้า Copy โค้ดไปวางใหม่ **ทั้ง 2 ไฟล์** เลยนะครับ:

### 1️⃣ โค้ดสำหรับไฟล์ `Code.gs` (ฝั่งหลังบ้าน)
*ผมแก้เพิ่มให้มันสามารถ "แสดงหน้าเว็บ" และ "ส่งข้อมูลมิเตอร์" ได้ในไฟล์เดียวกันแล้วครับ*
ให้ Copy โค้ดด้านล่างนี้ ไปทับของเดิมใน `Code.gs` ทั้งหมดครับ:

```javascript
const SHEET_ID = '1VtTFuhbxVVUGvCPjEtmK9RbnDzW2XOmWYZ49rfLoZNw';

function doOptions(e) {
  return ContentService.createTextOutput("")
    .setMimeType(ContentService.MimeType.TEXT)
    .setHeader("Access-Control-Allow-Origin", "*")
    .setHeader("Access-Control-Allow-Methods", "POST, GET, OPTIONS")
    .setHeader("Access-Control-Allow-Headers", "Content-Type");
}

function doGet(e) {
  try {
    const action = e.parameter.action;
    const parkingLot = e.parameter.lot;

    // ถ้ามีการขอข้อมูล (กดปุ่มดึงข้อมูล) ให้ส่ง JSON กลับไป
    if (action === 'getLast' && parkingLot) {
      let sheet = SpreadsheetApp.openById(SHEET_ID).getActiveSheet();
      let data = sheet.getDataRange().getValues();
      let lastInEnd = "";
      let lastOutEnd = "";
      
      for (let i = data.length - 1; i >= 1; i--) {
        if (data[i][0] === parkingLot) {
          lastInEnd = data[i][4] || ""; 
          lastOutEnd = data[i][6] || ""; 
          break;
        }
      }
      return ContentService.createTextOutput(JSON.stringify({
        "status": "success",
        "inEndMeter": lastInEnd,
        "outEndMeter": lastOutEnd
      })).setMimeType(ContentService.MimeType.JSON)
         .setHeader("Access-Control-Allow-Origin", "*");
    }
    
    // ถ้าเข้าเว็บตามปกติ ให้เปิดหน้าเว็บ (Index.html)
    return HtmlService.createHtmlOutputFromFile('Index')
      .setTitle('บันทึกหน่วยมิเตอร์')
      .addMetaTag('viewport', 'width=device-width, initial-scale=1');
      
  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({"status": "error", "message": error.toString()}))
      .setMimeType(ContentService.MimeType.JSON)
      .setHeader("Access-Control-Allow-Origin", "*");
  }
}

function doPost(e) {
  try {
    let data = JSON.parse(e.postData.contents);
    let sheet = SpreadsheetApp.openById(SHEET_ID).getActiveSheet();
    
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        "ลานจอด", "วันที่ (Date)", "เวลา (Time)", "มิเตอร์ขาเข้า (เริ่ม)", "มิเตอร์ขาเข้า (จบ)", 
        "มิเตอร์ขาออก (เริ่ม)", "มิเตอร์ขาออก (จบ)", "จำนวนหน่วย", "รวมเงิน", "หักเป็นเงินทอน", "ยอดเงินสุทธิ",
        "เงินสด", "เงินโอน", 
        "ลายเซ็นผู้ส่ง", "ลายเซ็นผู้รับ", "รูปถ่ายมิเตอร์ขาเข้า", "รูปถ่ายมิเตอร์ขาออก", "ลิงก์ไฟล์ PDF", "Timestamp"
      ]);
    }

    function saveImageToDrive(base64String, filename) {
      if (!base64String) return "";
      let base64Data = base64String.split(',')[1];
      if (!base64Data) return "";
      
      let blob = Utilities.newBlob(Utilities.base64Decode(base64Data), 'image/jpeg', filename);
      let folderName = "YC_Meter_Images";
      let folders = DriveApp.getFoldersByName(folderName);
      let folder = folders.hasNext() ? folders.next() : DriveApp.createFolder(folderName);
      
      folder.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW);
      let file = folder.createFile(blob);
      file.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW);
      return file.getUrl();
    }

    let ts = new Date().getTime().toString();
    let senderUrl = saveImageToDrive(data.senderSign, 'sender_' + ts + '.jpg');
    let receiverUrl = saveImageToDrive(data.receiverSign, 'receiver_' + ts + '.jpg');
    let photoInUrl = saveImageToDrive(data.photoIn, 'photoIn_' + ts + '.jpg');
    let photoOutUrl = saveImageToDrive(data.photoOut, 'photoOut_' + ts + '.jpg');

    let htmlContent = `
      <div style="font-family: sans-serif; padding: 20px;">
        <h2 style="text-align:center;">ใบจดมิเตอร์ ${data.parkingLot}</h2>
        <table style="width:100%; border-collapse: collapse;">
          <tr><td style="padding: 8px; border: 1px solid #ddd;"><strong>วันที่และเวลา:</strong></td><td style="padding: 8px; border: 1px solid #ddd;">${data.date} ${data.time}</td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd;"><strong>ลานจอด:</strong></td><td style="padding: 8px; border: 1px solid #ddd;">${data.parkingLot}</td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd; background-color: #f9f9f9;" colspan="2"><strong>มิเตอร์ฝั่งขาเข้า (IN) - ไม่คิดเงิน</strong></td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd;">มิเตอร์ขาเข้า (เริ่ม):</td><td style="padding: 8px; border: 1px solid #ddd;">${data.inStartMeter}</td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd;">มิเตอร์ขาเข้า (จบ):</td><td style="padding: 8px; border: 1px solid #ddd;">${data.inEndMeter}</td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd; background-color: #f9f9f9;" colspan="2"><strong>มิเตอร์ฝั่งขาออก (OUT) - คิดเงิน</strong></td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd;">มิเตอร์ขาออก (เริ่ม):</td><td style="padding: 8px; border: 1px solid #ddd;">${data.outStartMeter}</td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd;">มิเตอร์ขาออก (จบ):</td><td style="padding: 8px; border: 1px solid #ddd;">${data.outEndMeter}</td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd;"><strong>จำนวนหน่วย (รถ):</strong></td><td style="padding: 8px; border: 1px solid #ddd;">${data.units}</td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd;"><strong>รวมเงินมิเตอร์ (บาท):</strong></td><td style="padding: 8px; border: 1px solid #ddd;">${data.totalMoney}</td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd; color: red;"><strong>หักเป็นเงินทอน (บาท):</strong></td><td style="padding: 8px; border: 1px solid #ddd; color: red;">${data.deductFloat}</td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd; font-size: 18px;"><strong>ยอดเงินสุทธิที่ต้องส่ง (บาท):</strong></td><td style="padding: 8px; border: 1px solid #ddd; font-size: 18px;"><strong>${data.netCash}</strong></td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd;"><strong>เงินสด:</strong></td><td style="padding: 8px; border: 1px solid #ddd;">${data.cash}</td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd;"><strong>เงินโอน:</strong></td><td style="padding: 8px; border: 1px solid #ddd;">${data.transfer}</td></tr>
        </table>
        <br>
        <table style="width:100%; text-align: center;">
          <tr>
            <td style="width:50%;">
              ${data.senderSign ? '<img src="' + data.senderSign + '" style="height:100px;">' : ''}
              <br>ผู้จดมิเตอร์ (ผู้ส่งเงิน)
            </td>
            <td style="width:50%;">
              ${data.receiverSign ? '<img src="' + data.receiverSign + '" style="height:100px;">' : ''}
              <br>การเงิน (ผู้รับเงิน)
            </td>
          </tr>
        </table>
      </div>
    `;

    let pdfBlob = Utilities.newBlob(htmlContent, MimeType.HTML).getAs(MimeType.PDF);
    let safeLot = data.parkingLot.replace(/\s+/g, '_');
    pdfBlob.setName(`Receipt_${safeLot}_${data.date}_${data.time.replace(':','')}.pdf`);
    
    let folderNamePdf = "YC_Meter_PDFs";
    let foldersPdf = DriveApp.getFoldersByName(folderNamePdf);
    let folderPdf = foldersPdf.hasNext() ? foldersPdf.next() : DriveApp.createFolder(folderNamePdf);
    folderPdf.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW);
    
    let pdfFile = folderPdf.createFile(pdfBlob);
    pdfFile.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW);
    let pdfUrl = pdfFile.getUrl();

    sheet.appendRow([
      data.parkingLot, data.date, data.time, data.inStartMeter, data.inEndMeter, 
      data.outStartMeter, data.outEndMeter, data.units, data.totalMoney, data.deductFloat, data.netCash,
      data.cash, data.transfer, senderUrl, receiverUrl, photoInUrl, photoOutUrl, pdfUrl, new Date()
    ]);

    return ContentService.createTextOutput(JSON.stringify({"status": "success", "pdf": pdfUrl}))
      .setMimeType(ContentService.MimeType.JSON)
      .setHeader("Access-Control-Allow-Origin", "*");

  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({"status": "error", "message": error.toString()}))
      .setMimeType(ContentService.MimeType.JSON)
      .setHeader("Access-Control-Allow-Origin", "*");
  }
}
```

```html
  async function fetchLatestMeter() {

  function setupCanvas(canvasId) {
    const canvas = document.getElementById(canvasId);
    const ctx = canvas.getContext('2d');
    let isDrawing = false; let lastX = 0; let lastY = 0;
    
    // ตั้งเวลาหน่วงให้ UI โหลดเสร็จก่อนจับขนาด Canvas (แก้ปัญหาลากเส้นไม่ติด)
    setTimeout(() => {
      const rect = canvas.getBoundingClientRect();
      canvas.width = rect.width; canvas.height = rect.height;
      ctx.lineWidth = 2; ctx.lineCap = 'round'; ctx.strokeStyle = '#000';
    }, 500);

    function getPos(evt) {
      const rect = canvas.getBoundingClientRect();
      const scaleX = canvas.width / rect.width; const scaleY = canvas.height / rect.height;
      if(evt.touches) return { x: (evt.touches[0].clientX - rect.left)*scaleX, y: (evt.touches[0].clientY - rect.top)*scaleY };
      return { x: (evt.clientX - rect.left)*scaleX, y: (evt.clientY - rect.top)*scaleY };
    }
    function startDraw(e) { e.preventDefault(); isDrawing = true; const p = getPos(e); lastX = p.x; lastY = p.y; }
    function draw(e) { if (!isDrawing) return; e.preventDefault(); const p = getPos(e); ctx.beginPath(); ctx.moveTo(lastX, lastY); ctx.lineTo(p.x, p.y); ctx.stroke(); lastX = p.x; lastY = p.y; }
    function endDraw(e) { e.preventDefault(); isDrawing = false; }
    canvas.addEventListener('mousedown', startDraw); canvas.addEventListener('mousemove', draw); canvas.addEventListener('mouseup', endDraw); canvas.addEventListener('mouseout', endDraw);
    canvas.addEventListener('touchstart', startDraw, {passive: false}); canvas.addEventListener('touchmove', draw, {passive: false}); canvas.addEventListener('touchend', endDraw, {passive: false});
    return { canvas, ctx };
```

```javascript
function doGet(e) {
  try {
    const action = e.parameter.action;
    const parkingLot = e.parameter.lot;
    const callback = e.parameter.callback;

    // ถ้ามีการขอข้อมูล ให้ดึงเลขมิเตอร์ล่าสุด

      let data = sheet.getDataRange().getValues();
      let lastInEnd = "";
      let lastOutEnd = "";
      
      for (let i = data.length - 1; i >= 1; i--) {
        if (data[i][0] === parkingLot) {
          lastInEnd = data[i][4] || ""; 
          lastOutEnd = data[i][6] || "";

      if (callback) {
        return ContentService.createTextOutput(callback + "(" + JSON.stringify(result) + ")")
          .setMimeType(ContentService.MimeType.JAVASCRIPT);
      } else {
        return ContentService.createTextOutput(JSON.stringify(result))
          .setMimeType(ContentService.MimeType.JSON)
          .setHeader("Access-Control-Allow-Origin", "*");
      }
    }
      
  } catch (error) {
    let result = {"status": "error", "message": error.toString()};
    let callback = e.parameter.callback;
    if (callback) {
      return ContentService.createTextOutput(callback + "(" + JSON.stringify(result) + ")")
        .setMimeType(ContentService.MimeType.JAVASCRIPT);
    }
    return ContentService.createTextOutput(JSON.stringify(result))
```

ตอนนี้ผมได้เพิ่มกฎ **บังคับถ่ายรูปมิเตอร์ (ทั้งเข้าและออก)** และ **บังคับเซ็นชื่อ (ทั้งผู้ส่งและผู้รับ)** เข้าไปในโค้ดใหม่เรียบร้อยแล้ว พร้อมแก้คำว่า `ผู้ส่งเงิน` และ `ผู้จดมิเตอร์ (การเงิน)` ตามที่คุณลูกค้าบอกเป๊ะเลยครับ

**วิธีแก้ปัญหาแคชมือถือ (เพื่อให้โค้ดใหม่ทำงาน):**
1. **ถ้าใช้ iPhone (Safari):** ให้ปิดแท็บเว็บนี้ทิ้งไปก่อน -> แล้วลองเปิดเว็บด้วยโหมด **"Private Browsing (ส่วนตัว)"** ดูครับ (หรือไปที่ Settings > Safari > Clear History and Website Data)
2. **ถ้าใช้ Android (Chrome):** ปิดแท็บทิ้ง -> ไปที่ Settings ของ Chrome -> Clear browsing data -> เลือก Cached images and files -> แล้วเปิดเว็บใหม่ครับ

🚨 **ส่วนสุดท้าย: อัปเดตใบเสร็จ PDF หลังบ้าน**
เพื่อให้ข้อความใน **ไฟล์ PDF** เปลี่ยนจาก "ผู้จดมิเตอร์ (ผู้ส่งเงิน)" กลายเป็น "ผู้จดมิเตอร์ (การเงิน)" ตามไปด้วย รบกวนคุณลูกค้า Copy โค้ดด้านล่างนี้ไปวางทับใน `Code.gs` แล้วกด **Deploy -> New version** อีกรอบนะครับ:

```javascript
const SHEET_ID = '1VtTFuhbxVVUGvCPjEtmK9RbnDzW2XOmWYZ49rfLoZNw';

function doOptions(e) {
  return ContentService.createTextOutput("")
    .setMimeType(ContentService.MimeType.TEXT)
    .setHeader("Access-Control-Allow-Origin", "*")
    .setHeader("Access-Control-Allow-Methods", "POST, GET, OPTIONS")
    .setHeader("Access-Control-Allow-Headers", "Content-Type");
}

function doGet(e) {
  try {
    const action = e.parameter.action;
    const parkingLot = e.parameter.lot;
    const callback = e.parameter.callback;

    if (action === 'getLast' && parkingLot) {
      let sheet = SpreadsheetApp.openById(SHEET_ID).getActiveSheet();
      let data = sheet.getDataRange().getValues();
      let lastInEnd = "";
      let lastOutEnd = "";
      
      for (let i = data.length - 1; i >= 1; i--) {
        if (data[i][0] === parkingLot) {
          lastInEnd = data[i][4] || ""; 
          lastOutEnd = data[i][6] || ""; 
          break;
        }
      }
      
      let result = {
        "status": "success",
        "inEndMeter": lastInEnd,
        "outEndMeter": lastOutEnd
      };

      if (callback) {
        return ContentService.createTextOutput(callback + "(" + JSON.stringify(result) + ")")
          .setMimeType(ContentService.MimeType.JAVASCRIPT);
      } else {
        return ContentService.createTextOutput(JSON.stringify(result))
          .setMimeType(ContentService.MimeType.JSON)
          .setHeader("Access-Control-Allow-Origin", "*");
      }
    }
      
  } catch (error) {
    let result = {"status": "error", "message": error.toString()};
    let callback = e.parameter.callback;
    if (callback) {
      return ContentService.createTextOutput(callback + "(" + JSON.stringify(result) + ")")
        .setMimeType(ContentService.MimeType.JAVASCRIPT);
    }
    return ContentService.createTextOutput(JSON.stringify(result))
      .setMimeType(ContentService.MimeType.JSON)
      .setHeader("Access-Control-Allow-Origin", "*");
  }
}

function doPost(e) {
  try {
    let data = JSON.parse(e.postData.contents);
    let sheet = SpreadsheetApp.openById(SHEET_ID).getActiveSheet();
    
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        "ลานจอด", "วันที่ (Date)", "เวลา (Time)", "มิเตอร์ขาเข้า (เริ่ม)", "มิเตอร์ขาเข้า (จบ)", 
        "มิเตอร์ขาออก (เริ่ม)", "มิเตอร์ขาออก (จบ)", "จำนวนหน่วย", "รวมเงิน", "หักเป็นเงินทอน", "ยอดเงินสุทธิ",
        "เงินสด", "เงินโอน", 
        "ลายเซ็นผู้ส่ง", "ลายเซ็นผู้รับ", "รูปถ่ายมิเตอร์ขาเข้า", "รูปถ่ายมิเตอร์ขาออก", "ลิงก์ไฟล์ PDF", "Timestamp"
      ]);
    }

    function saveImageToDrive(base64String, filename) {
      if (!base64String) return "";
      let base64Data = base64String.split(',')[1];
      if (!base64Data) return "";
      let blob = Utilities.newBlob(Utilities.base64Decode(base64Data), 'image/jpeg', filename);
      let folderName = "YC_Meter_Images";
      let folders = DriveApp.getFoldersByName(folderName);
      let folder = folders.hasNext() ? folders.next() : DriveApp.createFolder(folderName);
      folder.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW);
      let file = folder.createFile(blob);
      file.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW);
      return file.getUrl();
    }

    let ts = new Date().getTime().toString();
    let senderUrl = saveImageToDrive(data.senderSign, 'sender_' + ts + '.jpg');
    let receiverUrl = saveImageToDrive(data.receiverSign, 'receiver_' + ts + '.jpg');
    let photoInUrl = saveImageToDrive(data.photoIn, 'photoIn_' + ts + '.jpg');
    let photoOutUrl = saveImageToDrive(data.photoOut, 'photoOut_' + ts + '.jpg');

    let htmlContent = `
      <div style="font-family: sans-serif; padding: 20px;">
        <h2 style="text-align:center;">ใบจดมิเตอร์ ${data.parkingLot}</h2>
        <table style="width:100%; border-collapse: collapse;">
          <tr><td style="padding: 8px; border: 1px solid #ddd;"><strong>วันที่และเวลา:</strong></td><td style="padding: 8px; border: 1px solid #ddd;">${data.date} ${data.time}</td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd;"><strong>ลานจอด:</strong></td><td style="padding: 8px; border: 1px solid #ddd;">${data.parkingLot}</td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd; background-color: #f9f9f9;" colspan="2"><strong>มิเตอร์ฝั่งขาเข้า (IN) - ไม่คิดเงิน</strong></td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd;">มิเตอร์ขาเข้า (เริ่ม):</td><td style="padding: 8px; border: 1px solid #ddd;">${data.inStartMeter}</td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd;">มิเตอร์ขาเข้า (จบ):</td><td style="padding: 8px; border: 1px solid #ddd;">${data.inEndMeter}</td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd; background-color: #f9f9f9;" colspan="2"><strong>มิเตอร์ฝั่งขาออก (OUT) - คิดเงิน</strong></td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd;">มิเตอร์ขาออก (เริ่ม):</td><td style="padding: 8px; border: 1px solid #ddd;">${data.outStartMeter}</td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd;">มิเตอร์ขาออก (จบ):</td><td style="padding: 8px; border: 1px solid #ddd;">${data.outEndMeter}</td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd;"><strong>จำนวนหน่วย (รถ):</strong></td><td style="padding: 8px; border: 1px solid #ddd;">${data.units}</td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd;"><strong>รวมเงินมิเตอร์ (บาท):</strong></td><td style="padding: 8px; border: 1px solid #ddd;">${data.totalMoney}</td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd; color: red;"><strong>หักเป็นเงินทอน (บาท):</strong></td><td style="padding: 8px; border: 1px solid #ddd; color: red;">${data.deductFloat}</td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd; font-size: 18px;"><strong>ยอดเงินสุทธิที่ต้องส่ง (บาท):</strong></td><td style="padding: 8px; border: 1px solid #ddd; font-size: 18px;"><strong>${data.netCash}</strong></td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd;"><strong>เงินสด:</strong></td><td style="padding: 8px; border: 1px solid #ddd;">${data.cash}</td></tr>
          <tr><td style="padding: 8px; border: 1px solid #ddd;"><strong>เงินโอน:</strong></td><td style="padding: 8px; border: 1px solid #ddd;">${data.transfer}</td></tr>
        </table>
        <br>
        <table style="width:100%; text-align: center;">
          <tr>
            <td style="width:50%;">
              ${data.senderSign ? '<img src="' + data.senderSign + '" style="height:100px;">' : ''}
              <br>ผู้ส่งเงิน
            </td>
            <td style="width:50%;">
              ${data.receiverSign ? '<img src="' + data.receiverSign + '" style="height:100px;">' : ''}
              <br>ผู้จดมิเตอร์ (การเงิน)
            </td>
          </tr>
        </table>
      </div>
    `;

    let pdfBlob = Utilities.newBlob(htmlContent, MimeType.HTML).getAs(MimeType.PDF);
    let safeLot = data.parkingLot.replace(/\s+/g, '_');
    pdfBlob.setName(`Receipt_${safeLot}_${data.date}_${data.time.replace(':','')}.pdf`);
    
    let folderNamePdf = "YC_Meter_PDFs";
    let foldersPdf = DriveApp.getFoldersByName(folderNamePdf);
    let folderPdf = foldersPdf.hasNext() ? foldersPdf.next() : DriveApp.createFolder(folderNamePdf);
    folderPdf.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW);
    
    let pdfFile = folderPdf.createFile(pdfBlob);
    pdfFile.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW);
    let pdfUrl = pdfFile.getUrl();

    sheet.appendRow([
      data.parkingLot, data.date, data.time, data.inStartMeter, data.inEndMeter, 
      data.outStartMeter, data.outEndMeter, data.units, data.totalMoney, data.deductFloat, data.netCash,
      data.cash, data.transfer, senderUrl, receiverUrl, photoInUrl, photoOutUrl, pdfUrl, new Date()
    ]);

    return ContentService.createTextOutput(JSON.stringify({"status": "success", "pdf": pdfUrl}))
      .setMimeType(ContentService.MimeType.JSON)
      .setHeader("Access-Control-Allow-Origin", "*");

  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({"status": "error", "message": error.toString()}))
      .setMimeType(ContentService.MimeType.JSON)
      .setHeader("Access-Control-Allow-Origin", "*");
  }
}
```

- เปลี่ยน "หักเป็นเงินทอนตั้งต้น (บาท)" ➡️ **"หักเป็นเงินทอน (บาท)"**
- เปลี่ยน "จำนวนหน่วย (+1)" ➡️ **"จำนวนหน่วย"**
- เปลี่ยน "ภาพถ่ายมิเตอร์ (จบกะ)" ➡️ **"ภาพถ่ายมิเตอร์"**
- เปลี่ยน "ผู้ส่งเงิน (ผู้จดมิเตอร์)" ➡️ **"เจ้าหน้าที่จุดรับฝากรถมอเตอร์ไซค์"**
